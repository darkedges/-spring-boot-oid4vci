Obtain credentials

Drives the whole pre-authorized_code flow server-side: fetches the issuer's metadata and a fresh demo offer, exchanges the code for an access token, builds real proofs of possession, and requests every credential configuration the issuer offers.

This call happens server-side, from inside the wallet's own JVM/container — not from your browser. Running under docker compose? Use the issuer's compose service name (e.g. http://issuer:8092), not localhost: the wallet container can't reach the issuer container via localhost, only your host's browser can.
