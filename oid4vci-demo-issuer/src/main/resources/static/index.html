Seeds a single-use pre-authorized code (claims given_name: Jane, family_name: Doe) and returns a Credential Offer for it, per the pre-authorized_code grant. This is what a real wallet would scan as a QR code or deep link. 


      

        
        
      

      

        This demo's own Wallet app (oid4vci-demo-wallet) doesn't consume this exact offer object —
        its "Obtain Credential(s)" button fetches a fresh one directly from this issuer's
        /demo/offer endpoint when you click it. The offer above is shown so you can see (and copy)
        exactly what a wallet receives, e.g. to paste into a different OID4VCI-compatible wallet.
